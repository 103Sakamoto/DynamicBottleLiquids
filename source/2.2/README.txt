Dynamic Bottle Liquids 2.2 for Fallout 4 desktop
Install the full FOMOD with your mod manager. Choose Fusion, Menu Framework, Dear Modding UI or No UI. Install F4SE and Address Library for your game version and the dependencies for your selected UI. Select patches for the bottle mods you use.
Disable previous DBL test overlays so their DLLs and shaders cannot override 2.2. Preserve personal UserSettings when upgrading.
Desktop runtime targets are OG 1.10.163, NG 1.10.984 and AE 1.11.240. Live SSR routing evidence covers OG and NG. The final 2.2 binaries have not been play-tested across the full runtime and UI matrix.
